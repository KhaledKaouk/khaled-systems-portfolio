PROBLEM SPACE

Database work can become cumbersome when a developer tool is heavyweight or when common workflows require too much navigation. This project explores a more direct, command-oriented workflow.

WHAT WAS BUILT

A SQL editor and debugger developed over four months, with AI capabilities integrated into the workflow.

ENGINEERING FOCUS
